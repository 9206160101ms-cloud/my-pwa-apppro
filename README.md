# دفترحساب — PWA آفلاین

وب‌اپلیکیشن local-first برای مدیریت بدهی/طلب، درآمد، فاکتور و انبار، با React + Vite + Tailwind CSS.

## اجرا

```bash
npm install
npm run dev
```

## تولید نسخه نهایی

```bash
npm run build
npm run preview
```

## قابلیت‌های پیاده‌سازی‌شده

- نگهداری کامل داده‌ها در `localStorage` با پیشوند `acc:` و بدون وابستگی به سرور
- داشبورد ارزش خالص، فعالیت‌های اخیر و میانبرها
- بدهی و طلب با پرداخت/تسویه جزئی
- مدیریت درآمد
- فاکتورساز چندردیفی، وضعیت پرداخت و دانلود تصویر PNG از فاکتور
- مشتریان، کالا، ورود/خروج تراکنشی انبار و جلوگیری از خروج بیش از موجودی
- گزارش کم‌موجودی و تاریخچه تمام تراکنش‌های انبار
- شش پوسته رنگی، فارسی/عربی، PIN هش‌شده با SHA-256 و پشتیبان JSON
- Manifest و service worker برای اجرای PWA و کش آفلاین پوسته برنامه

## نکات اجرایی

- اطلاعات فقط در مرورگر همان دستگاه ذخیره می‌شود؛ پیش از پاک‌سازی داده‌های مرورگر از بخش تنظیمات خروجی JSON تهیه کنید.
- اسکن QR از `getUserMedia` برای پیش‌نمایش دوربین استفاده می‌کند. رمزگشایی خودکار QR به یک موتور QR محلی اضافه نیاز دارد؛ در این نسخه ورودی دستی کد در همان پنجره فراهم است.
- قابلیت ورود بیومتریک (WebAuthn) وابسته به پشتیبانی مرورگر و ثبت credential دستگاه است و در این نسخه با PIN امن پوشش داده شده است.
